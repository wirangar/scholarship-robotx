# اکوسیستم هوشمند راهنمای دانشجویان بین‌المللی - جهان‌راه (GlobalGuide)

این پروژه یک اکوسیستم دیجیتال یکپارچه شامل ربات تلگرام، وب‌سایت و اپلیکیشن PWA است که برای راهنمایی دانشجویان بین‌المللی، با تمرکز اولیه بر شهر پروجا، ایتالیا، طراحی شده است.

## ✨ ویژگی‌های کلیدی

- **ربات تلگرام هوشمند**: پاسخگویی به سؤالات متداول، منوهای درختی، چندزبانگی و قابلیت اتصال به AI.
- **وب‌سایت حرفه‌ای**: طراحی مدرن، واکنش‌گرا، SEO-friendly و هماهنگ با محتوای ربات.
- **محتوای متمرکز**: تمام متون و داده‌ها از فایل‌های JSON مرکزی (`data/` و `lang/`) بارگذاری می‌شوند.
- **مقیاس‌پذیری**: طراحی شده برای گسترش آسان به شهرها، دانشگاه‌ها و زبان‌های جدید.

## 🚀 راه‌اندازی و نصب

برای اجرای این پروژه به صورت محلی، مراحل زیر را دنبال کنید:

### 1. پیش‌نیازها

- پایتون 3.8 یا بالاتر
- `pip` برای مدیریت بسته‌ها

### 2. نصب بسته‌ها

ابتدا پروژه را کلون کنید:
```bash
git clone <repository-url>
cd <project-directory>
```

سپس بسته‌های مورد نیاز پایتون را نصب کنید:
```bash
pip install -r requirements.txt
```

### 3. تنظیم متغیرهای محیطی

یک فایل `.env` در ریشه پروژه ایجاد کنید. می‌توانید از `.env.example` به عنوان الگو استفاده کنید:
```bash
cp .env.example .env
```

سپس مقادیر زیر را در فایل `.env` ویرایش کنید:
- `TELEGRAM_BOT_TOKEN`: توکن ربات تلگرام خود را که از [BotFather](https://t.me/BotFather) دریافت کرده‌اید، وارد کنید.
- `ADMIN_CHAT_ID`: شناسه عددی اکانت تلگرام خود را برای دریافت اعلان‌های ادمین وارد کنید.

### 4. اجرای ربات

برای اجرای ربات تلگرام، دستور زیر را اجرا کنید:
```bash
python main.py
```

ربات شما اکنون فعال و در حال اجرا است.

## 📂 ساختار پروژه

```
./
├── main.py             # فایل اصلی ربات تلگرام
├── config.py           # ماژول تنظیمات و متغیرهای محیطی
├── requirements.txt    # لیست بسته‌های پایتون
├── data/
│   └── content.json    # محتوای اصلی (بورسیه‌ها، مسکن و...)
├── lang/
│   ├── fa.json         # متون فارسی
│   ├── en.json         # متون انگلیسی
│   └── it.json         # متون ایتالیایی
├── assets/             # فایل‌های چندرسانه‌ای (PDF, تصاویر)
├── website/            # فایل‌های وب‌سایت
├── tests/              # تست‌های پروژه
├── .env.example        # نمونه فایل متغیرهای محیطی
├── .gitignore          # فایل‌های نادیده گرفته شده توسط گیت
└── README.md           # همین فایل
```
